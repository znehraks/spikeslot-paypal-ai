# Design Context

Audience: indie web creators and small advertisers.
Use case: discover a rising opt-in publisher, understand fit, compose and approve a sponsorship, buy it and see it live.
Tone confirmed by user: casual, free-spirited, image-led, like Higgsfield. Avoid a stiff finance dashboard.
Workflow: explore visual mood in Midjourney before implementing the UI. Midjourney is mood reference, not final interface text. Final typography, interactions and accessibility are implemented in code.
Language: English submission UI.
