# SpikeSlot

Find a rising creative service. Make a sponsorship that belongs there. Buy it with PayPal.

Hackathon MVP under development. Live AI and PayPal Sandbox verification are pending; this is not a completed submission.

## Scope
Registered publisher pool → measured/replayed traffic spike → AI fit analysis → site-specific sponsorship → human approval → fixed-price USD PayPal Sandbox order → visible placement and reporting.

See [the implementation contract](docs/SPEC.md). Outbound prospecting and messaging, real payouts, wallet balances and CPM settlement are outside this MVP.
